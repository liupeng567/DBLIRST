## 0 前置：IttdWindows 窗口对齐修复（M2 遗留缺陷，本日先行落地）

**缺陷**：`IttdWindows` 此前只做 NUC 校正+归一化，未消费 reg.npz——时序窗内背景随相机
晃动逐帧漂移，且 T=32 窗必跨 25 帧参考边界（M1 审计：跨块背景跳变 5–10 灰度级）。
T-MSD3D 代码注释明示设计假设是"配准后残余背景运动已被 M1 消解"，数据集漏掉了这一步。

**修复**（唯一入口 = M1 敲定的 `align_to_anchor`，未重新发明）：
- `dsld/data/ittd_window_dataset.py`：window 模式每窗对齐到窗口首帧锚点（块内
  M_t∘M_a⁻¹，跨块经 bridge_M 过桥，`warpAffine …|WARP_INVERSE_MAP` 采样）；框填充
  掩码用同一 W 同步 warp（最近邻、界外补 0）；准恒等矩阵自动跳过重采样（静态相机
  免二次插值）；新增性质开关 `align`（消融对照）；`quality.npy` 窗口中位数随样本输出
  （M1 报告 §8 要求的"数据集类必消费"第 3 项，供 FiLM 质量条件）。frame 模式不变
  （MSHNet 已训 ckpt 兼容）。
- `dsld/data/preprocess/register.py`：`align_to_anchor` 平坦参考块的 NaN 桥（M1 缓存
  已知缺口）从 break 改为**恒等续链**（break 会在跨 2 个边界时把 M_t 作用在错误的
  参考系上）；新增 `window_anchor_warps` / `warp_frame` / `is_identity_warp`。
- `dsld/eval/infer_seq.py`：`infer_temporal` 与训练同口径——输入窗对齐锚点，输出概率
  再按同一 W **回投原始帧坐标**后重叠平均/对比 GT（输入侧 WARP_INVERSE_MAP 采样、
  输出侧默认正向回投，同一矩阵两种语义，已推导并测试）。
- 验证：合成平移序列端到端（对齐后背景逐帧残差 <0.05 归一化域，未对齐对照 >3×）、
  NaN 桥续链矩阵恒等式、掩码中心跟随 W⁻¹ 映射，真实缓存 seq_0001 回归——全部通过。

**关键设计决策**（方案条文互洽化，均已在代码 docstring 记录）：
1. **ŷ_B 为 32ch 特征域重构**（bg_head c_h→c_in）：3.2 表 M"背景预测头 32→1"与 7.1①
   "分割头输入 [α⊙残差, h_T] 64→1"矛盾——64 = 32(残差)+32(h_T) 只在残差为 32ch 时
   成立，故按特征域重构解读（"32→1"读作"1×1 conv、1 倍尺度"）。
2. **临时门控 α**（M3 占位）：α=σ(conv1x1([x−ŷ_B, h_T]))，零初始化=中性门 0.5 起步；
   M4 换三重一致性门控（z_B, r_T, LR）时数据流不变。零初始化同时保证初始化期
   (α>α_th)=空 → 反馈掩码≡0 → L_recon 有效区不被未训练 α 污染。
3. **反馈掩码阈值化**：4.5"高 α 峰值"实现为 (α>α_th=0.5) 二值化后膨胀——实测未阈值
   膨胀会把整幅背景打码（α sigmoid 基线 0.4–0.5），掩码值域 {0}∪{0.9ᵏ}∪1。
4. **单状态消融（10.8-a）**：单条液态流（无背景/目标分立、无级联），τ 范围取并集
   [2,256]（结构先验假设的直接对照组），其余组件逐一同构。
5. **GhostNetV2 DFC**：保持官方 layer_id>1 规则（首个 stride-4 块仍原始 Ghost 模块），
   忠实官方口径，与方案"stride≥4 启用"有一块的出入（v1.3 允许范围）。

## 2 验证结果（本机 RTX 4060 Laptop 8GB）

- **单测**：15 项（dsld_core）+ 4 项（对齐）+ 既有 30 项回归 = 49 项全过。
- **冒烟训练**（真实 ITTD，limit_seqs=2，T=8 crop 240×320 B=1）：62 步 loss 0.50→0.51
  无 NaN，ckpt 含优化器状态可续训。
- **真实配置冒烟**（T=32 crop 240×320 B=2 accum4 checkpoint）：2 轮 28 步×2，分量
  seg 0.512 / recon 0.261 / dec 0.024，τ_B=48 τ_T=6（init，在界内），‖h‖_rms 0.27/0.17
  （阈 100），eval 全链通（对齐窗口→概率回投→指标/官方分/效率）。
- **参数量实测（1.0×）**：encoder 0.041M + neck 0.053M + core 0.016M = **0.111M**
  （≤5M 闸门余量巨大；方案 4.7"骨干 ≈2.0M"为含深层级的估算，截断到 stride-8 后实际
  小一个量级——容量不足时先升 width 1.3× 与 c_h，不必改结构）。
- **效率**：2.96 GFLOPs/帧（方案 4.6 lite 配置口径 12–15G 的 1/4，因截断+窄颈）。
