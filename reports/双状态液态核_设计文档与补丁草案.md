## 1. 原理起点：什么叫"液态"

普通 RNN 的更新是 `h_t = φ(W[h_{t-1}, x_t])`——时间尺度**隐含在权重里**，无法说出某个单元"记多久"。

**LTC（Liquid Time-Constant Networks）** 的核心主张是把时间常数变成显式且**输入相关**的量：

```
dx/dt = −[1/τ + f(x, I)]·x + f(x, I)·A
```

关键在 `f` 位于括号**内部**，于是有效时间常数为

```
τ_eff = 1 / (1/τ + f(x, I))
```

画面剧变时 `f` 增大 → `τ_eff` 变小 → 状态"变稀"、快速跟随；画面平稳时 `f→0` → `τ_eff→τ` → 状态"变稠"、长期记忆。**这是"液态"的定义：单元的时间尺度随输入流动。** 它同时解释了 LTC 的表达力来源——固定 τ 的 RNN 必须靠权重堆叠去逼近不同尺度，LTC 把该自由度显式放进动力学。

**CfC** 的作用是对上式求闭式解，免掉数值积分器。该 ODE 的通解为

```
x(t) = e^{−(1/τ+f)·t}·x(0) + [1 − e^{−(1/τ+f)·t}]·A
```

即"**衰减系数 × 旧状态 + (1 − 衰减系数) × 吸引子**"。CfC 进一步用 `σ(−z)` 替代 `e^{−z}`，使单步可算：

```
x(t) = σ(−(1/τ+f)·t)·x(0) + [1 − σ(−(1/τ+f)·t)]·A
```

**注意该式的结构**：旧状态 `x(0)` 是**显式保留项**，吸引子 `A` 是**学出的候选**，两者之间是一个由速率与经过时间共同决定、必然落在 (0,1) 的衰减系数。

## 2. 双状态成立所需的七条设计要点

| # | 要点 | 不满足时的退化解 |
| --- | --- | --- |
| 1 | **显式泄漏路径**：旧状态以系数 `a ∈ (0,1)` 直接留在更新式内 | 旧状态仅作为拼接输入进入学习头 → 无记忆保证 |
| 2 | **τ 出现在泄漏速率里**，速率为正定、逐单元的显式参数 | τ 只是自由门控的分母 → 网络学 `f ∝ τ` 抵消它 |
| 3 | **输入相关但有界**：`λ = λ_base·(1 + s·σ(·))`，`s` 有上限 | 无界调制 → 尺度顺序可被任意颠倒 |
| 4 | **输入流分离**：慢状态吃背景，快状态吃背景解释不掉的残差 | 两状态看同一输入 → 必然坍缩为同一表示 |
| 5 | **各司其职的监督**：慢状态被"预测背景"监督 | 慢状态失去变慢的理由，退化为分割损失的从属项 |
| 6 | **稳定的耦合**：快可读慢、不可写回；保护掩码有上下界 | 掩码饱和到 1 → 慢状态被断粮 |
| 7 | **可测的尺度分离**：Gate 测实现出来的衰减速率，不测参数 | 测 θ_τ → 参数达标而动力学无分离 |

**因果次序**：要点 4 的重要性高于要点 1–3。任务真正需要的是"**能被背景解释的像素就被抑制**"这一预测-残差机制；双时间尺度是让 `ŷ_B` 变慢的**手段**，输入流分离才是让 `ŷ_B` 保持干净的**手段**。实现优先级：**4 → 5 → 1/2/3 → 6 → 7**。

## 3. 对照本项目

### 3.1 方案 §4.2 的原文语义（判断基准）

方案 §4.2 给出的更新式与语义（原文）：

```
p(t) = σ(−f(h, x; θ_f)·Δt/τ),    h(t+Δt) = p⊙g + (1−p)⊙m
```

> "Δt = 1 帧。**p → 1 时状态被输入重写（快响应），p → 0 时状态保持历史（慢记忆）。**"
>
> "clip 边界即 3.2 节的 [16,256] / [2,16]，**硬约束保证双状态时间尺度分立假设不被训练破坏**"

方案 §4.4 对保持项的语义：

> "α 大时，p_T 被压向 0，状态走 **m 分支维持响应**"

**结论**：方案的语义是自洽的——`p` 是"写入权"、`m` 是"记忆分支"、保持项压小 `p` 即偏向 `m`。现有代码 `p·g + (1−p)·m` 与方案 §4.2 的字面公式一致。

### 3.2 但方案的语义无法由该公式保证（这是问题所在）

方案说"p → 0 时状态保持历史"。要 `p → 0`，需要 `|f|·Δt/τ ≳ 3`：

| 通道 | τ | 使 p ≤ 0.05 所需的 \|f\| |
| --- | --- | --- |
| h_B（init） | 48 | ≥ 144 |
| h_B（上界） | 256 | ≥ 768 |
| h_T（init） | 6 | ≥ 18 |

于是出现**两难**：

- **若 `|f|` 自由**：网络可学 `f ∝ τ`，任意 τ 都能配出同一个 `f/τ`，**τ 的硬 clip 只约束参数空间**（方案 §4.2 声称的"硬约束保证分立假设不被训练破坏"不成立）。
- **若限制 `|f|`（即已落地的 `bound_f`）**：`|f| ≤ bound` 使 `z = |f|/τ` 被压得很小，`σ` 落在 0.5 附近，**方案要求的"慢记忆"分支变得不可达**。代入 `bound_f = 1`：

  | 通道 | z 上界 | p 区间 |
  | --- | --- | --- |
  | h_B（τ=48） | 1/48 = 0.021 | [0.495, 0.505] |
  | h_T（τ=6） | 1/6 = 0.167 | [0.458, 0.542] |

  即 `h' ≈ 0.5·g + 0.5·m`——**几乎无记忆的前馈混合**，方向与目标相反。

**因此 `f_bound` 是一个"小则失效、大则不生效"的假解**：它让 `τ/|f| ≥ τ/bound` 成为结构性质（这一半是对的，`tau_report` 的 `eff_tau` 也确实变得可测），但代价是抽掉了门的动态范围。**唯一出路是取消 τ 路径上的自由乘子**，即把 τ 放进显式指数衰减——这正是下节形式。

## 4. 目标设计

### 4.1 单通道更新式（替换 `_LiquidChannel.step`）

```
λ_base = exp(clip(θ_λ, log(1/τ_max), log(1/τ_min)))        # 逐单元，【速率域】硬 clip
λ      = λ_base · exp(s_max·tanh(FiLM_f(f_head(inp))))     # 有界输入相关调制（"液态"）
         · (1 − κ·α_prev)                                  # 保持项：压小速率 = 延长记忆
a      = exp(−Δt·λ)                                        # 保留系数 ∈ (0,1)
cand   = tanh(FiLM_g(g_head(inp)) + m_scale·FiLM_m(m_head(inp)))
h'     = a ⊙ h + (1 − a) ⊙ cand
```

**与方案 §4.2 的对应**：`p ≡ (1−a)`（写入权），"p → 0 = 保持历史"由**保留项就是 `h` 本身**结构性保证，而不是靠 `m` 学出近似恒等。保持项压小 λ 即增大 `a`，与方案 §4.4"p_T 被压向 0、状态走记忆分支"完全同义。三个头（f/g/m）与逐头 FiLM 全部保留，无死参数。

**推荐默认值（含取值依据）**：

| 参数 | 建议值 | 依据 |
| --- | --- | --- |
| `tau_init` | B: 48 / T: 6（沿用） | 半衰期 = τ·ln2 → B: 33.3 帧、T: 4.2 帧，比值 8:1（手算） |
| `s_max` | 0.7 | τ 可被输入在 [0.50×, 2.01×] 内调制，有界且不颠倒尺度 |
| `kappa_max` | 0.5 | 保持项最多把 τ 延长 2×；τ_T: 6 → 12 帧，正对方案 §4.4"约 10 帧" |
| `κ` 初始化 | σ(θ_κ)·κ_max ≈ 0.2 | 起步延长 1.25×，留出学习空间 |
| `m_scale` | 0.5 | 候选精修项有界贡献，`tanh` 保证 `‖h‖` 有界 |

### 4.2 双通道装配与有界掩码（配套最小改动）

级联结构不变，只补掩码上界：

```
M(t) = min( max( peak_t, decay·M(t−1) ), m_max )
```

| 参数 | 建议值 | 依据 |
| --- | --- | --- |
| `m_max` | 0.8 | 输入最多被衰减 80%，**永不归零** → 慢通道不可能被断粮 |
| `alpha_th` | 0.6 | 与已落地的 α₀≈0.119 之间留 ≥3σ 裕度 |
| `softness` | 0（默认硬阈值） | 软化版会造成 α≈α_th 时全局弱泄漏（见补丁 A-4 的取舍表），非必要不启用 |

        """单步 CfC 更新。h/x_in: [B,C,H,W]；scene: [B,5]；alpha_prev: [B,1,H,W]。"""
        inp = torch.cat([h, x_in], dim=1)
        outs = []
        for i, head in enumerate((self.f_head, self.g_head, self.m_head)):
            o = head(inp)
            gamma, beta = self.film[i](scene).chunk(2, dim=1)
            o = o * (1.0 + gamma[:, :, None, None]) + beta[:, :, None, None]
            outs.append(o)
        f, g, m = outs
        if self.f_bound > 0:
            f = self.f_bound * torch.tanh(f / self.f_bound)
        with torch.no_grad():  # 有效速率监控（评审 2.3）：门控速率 = |f|·Δt/τ
            self.last_f_abs = float(f.abs().mean())
        tau = self.tau()  # [C_h]，fp32
        gate = -f * (dt / tau[None, :, None, None])
        if self.keep and alpha_prev is not None:
            gate = gate - F.softplus(self.theta_beta) * alpha_prev
        p = torch.sigmoid(gate)
        return p * g + (1.0 - p) * m

                        softness: float = 0.0) -> torch.Tensor:

    """L_dec（7.1③）：逐帧逐位置 cos²(h̄_T, h̄_B)，防双通道坍缩到同一表示。

```python
def decouple_loss(h_t: torch.Tensor, h_b: torch.Tensor, eps: float = 1e-6,
                  min_norm: float = 1e-2, norm_weight: float = 1.0) -> torch.Tensor:
    """L_dec（7.1③，评审 §4.3 修复版）：带范数下限的软正交。

    旧式 cos² = dot²/(n_t·n_b + eps)² 在任一状态塌缩到 0 时给出 0 —— 恰好放过它本该
    防止的坍缩（评审 §2 第 7 条）。修复两点：
      ① 分母用 clamp_min 设下限，使"双零"不再把 cos² 抹平；
      ② 显式惩罚范数低于 min_norm 的单元（norm_floor），坍缩必然产生正损失。
    值域：cos² ∈ [0,1]（Cauchy–Schwarz，clamp 仅作数值保险）。
    """
    h_t = h_t.float()
    h_b = h_b.float()
    dot = (h_t * h_b).sum(dim=2)                                   # [B,T,H,W]
    nt = h_t.norm(dim=2)
    nb = h_b.norm(dim=2)
    cos2 = (dot / (nt * nb).clamp_min(min_norm * min_norm)) ** 2
    cos2 = cos2.clamp(max=1.0)
    norm_floor = F.relu(min_norm - torch.minimum(nt, nb)).mean()   # 坍缩哨兵
    return cos2.mean() + norm_weight * norm_floor
```

| `h_B ≡ 0`（背景通道塌缩） | 0.0（无惩罚） | `0.01 > 0` ✅ |
| 两状态健康且正交 | ≈0 | ≈0 ✅ |
| 两状态健康且同向 | ≈1 | ≈1 ✅ |

参数预算影响：**无新增参数**（`min_norm` / `norm_weight` 为超参）。
